# 转场与交通

核查实际出行方向和真实起终点之间的门到门交通。反向路线、站间耗时不能直接替代正向门到门时间。
地点活动表示停留，交通放在活动之间的空档。考虑步行到站、进出站、等车、用餐、休息和同行者行动能力。
铁路分别安排出发站与到达站，列车运行位于两站的空档，两端市内接驳单独查证。通常另留至少二十分钟候车、十分钟出站，必要时增加；不能把列车整个运行时段当成在出发站停留。
同城多个车站按实际住宿、活动区域和班次比较完整门到门行程，优先减少不必要的远距离接驳、换乘与步行，而不是默认选城市主站。比较过的线路只作为取舍依据，地图只呈现实际选用的交通；没有轨迹时清楚标为示意。
步行或驾车通常另留至少五分钟、公交另留至少十分钟缓冲；拥堵、换乘、老人或大件行李需要更多时间。
有效路线继续使用，只查询受影响部分。区分暂无班次与查询服务故障，不在持续故障下反复请求。
