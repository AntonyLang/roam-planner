# 使用规划助手与地图

## 逐轮确认

先新建或打开旅程，在右侧“规划助手”说明大致想法。可以分几轮补充：

1. “想带爸妈去苏州两天，轻松一点。”
2. 回答日期、出发地、人数与到返时间。
3. 补预算、住宿、步行能力、一定要去或不想去的地点。
4. 查看地图与草稿，再要求取消、放慢或调整某一段。

规划期间可“补充要求”。助手完成后，草稿会出现在对应日期；点击活动定位，编辑时间或说明，再由助手整理新候选。点击“采用到旅程”后成为正式安排。

确认出行日期后，请检查旅程日历的起止日期；可以要求助手更新，也可在旅程编辑中设置。对话里提到日期与更新旅程日历是两个操作。

## 地图线型

| 线型 | 含义 |
| --- | --- |
| 路网实线 | 已采用、端点和方式相符的实际道路几何 |
| 路网虚线 | 草稿中的道路路线 |
| 铁路点划线 | 出发站到到达站的示意连接，非实际轨道 |
| 航段点线 | 两端机场的示意连接，非实际航路 |

点击日期可查看当天路线；点击地点可定位并查看详情。展开地图图例下的“路线详情”，可逐段查看方向、交通方式、时长和来源。示意线会注明班次是否核实；有示意线不代表已订票或存在实时库存。

如果更换了地点、顺序或交通方式，需要重新核实对应路线。没有可用来源时，助手应说明缺口，不能把两个点之间的直线当作道路查询结果。

## 采用后的修改

直接在原对话说明“修改已经采用的行程”和具体变化。助手可以从真实采用记录恢复日程绑定，修改后保存新的候选。再次采用应替换原范围，预算与住宿按新候选实际操作执行。

如果手工删除、移动或插入活动导致原范围断开，助手会要求根据当前日程重新选择范围。普通刷新可以恢复已保存会话；“停止”后也可继续表达新的要求。

## 费用与未确定事项

日程费用按同行者合计记录，预算账本独立管理。未订酒店、未定航班、估算价格与尚不可查的天气，应保留待确认说明。步行路线估时只覆盖对应转场，景区内部游览、排队和临时绕行需另留余量。
