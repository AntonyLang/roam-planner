# 常见问题

## 网页可打开，规划服务不可用

在首页打开“服务配置”，确认模型 Key、模型 ID、服务地址并检查连接。兼容服务地址需要能从容器访问；检查还会验证工具调用支持。页面保存后下次规划生效。仍不可用时检查 `docker compose ps` 和 `docker compose logs --tail 100 agent sources`。

## 小红书扫码失败或过期

先启用并保存来源，再开始扫码。二维码由 Sources 容器里的 Chromium 生成；本人用小红书 App 确认，遇到平台验证需自行处理。只有真实用户接口确认后才显示已登录。浏览器启动失败请检查 Sources 日志和镜像版本；过期时重新扫码，未登录不会阻挡其他来源。

## 地点或路线查询失败

确认高德 Key 是 Web 服务类型。认证失败、无结果、连接失败是不同情况；反复更换关键词不能修复连接故障。选择 Geoapify 时需填写其 Key，且该适配器支持步行、驾车路网估时，不提供公交查询。

## 地图有地点，没有道路

地点坐标不会自动证明两点之间有可用道路。查看助手是否取得对应起终点、方向和交通方式的路线；打车使用驾车模式。修改地点或交通方式后请重新查询。铁路和飞机使用显式示意段，不用公路路线替代。

## 更新后还是旧页面

刷新浏览器；PWA 可能需要关闭应用页面后重新打开并再次刷新。保留旅程和会话数据，无需先清空站点存储。

## 日历标题与日期不一致

先检查旅程编辑中的起止日期，对话中的日期不会单独触发日历更新。浏览器的时区修改扩展也可能改写所有网站的日期显示；若扩展强制覆盖时区，检查其对本站的作用范围。

## 天气、价格或班次无法确定

天气接口最多提供未来 16 天预报；更远日期不能用常年气候值冒充预报。酒店价格、双床房库存、餐馆排队、航班与铁路余票需要临近出行再次确认。当前产品不出票、不预订。

## 已采用的行程无法直接续改

原范围中的活动可能已被手动删除、换日或被插入打断。让助手读取当前旅程并重新选定修订范围，保留已有预算与住宿。若同一地点还被修改范围外的日程引用，改变其费用会被拒绝；先确认需要一起修改的范围，不同活动费用可使用独立地点记录。
